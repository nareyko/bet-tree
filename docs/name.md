# The Bet Tree — name page

The Bet Tree is a method by Vadim Nareyko for working with an uncertain future: one measurable claim, one checkable week, unknowns left as unknown.

Contact: vadim@nareyko.com · [github.com/nareyko/bet-tree](https://github.com/nareyko/bet-tree)

## What this is

A founder writes a bet before the market has proved the idea. The week turns that bet into an action, an early customer signal, a success line, a safety line, and a Friday decision. When one sheet is no longer enough, the same method opens a tree of linked claims.

Start with the [method](method.md), then [First week](first-week.md).

## What this is not

- Not a poker **betting tree** (bet sizes in solvers).
- Not gambling or **sports betting**.
- Not a classical **decision tree** with known probabilities already filled in.
- Not Shape Up's **bet**: a decision to give a team a fixed build cycle.
