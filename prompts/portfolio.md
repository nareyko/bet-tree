# Prompts for a portfolio under one long bet

Use when several living subprojects hang from one 3–5 year Business or Founder stake. Do this **before** filling a single week sheet for "everything".

The assistant asks and waits. It does not invent numbers. Unknown stays **unknown**. Match blanks: [09-portfolio-cycle-map](../templates/09-portfolio-cycle-map.md), [10-subproject-checklist](../templates/10-subproject-checklist.md).

Do not use private product names in anything that will be committed to a public repo. Prefer generic labels (Project A, outreach, build, research).

## 1. Long bet and why this cycle exists

```
Study the project notes the user shared. Do not invent a 3–5 year stake.

Ask one question: is the far stake on Business, on Founder, or on both? Wait.

Ask for a qualitative 3–5 year picture in one or two sentences. If they have no number, write unknown. Wait.

Ask how this week's work should serve that far stake, in one sentence. Wait.

Show a short draft of the top of the portfolio map (category, horizon words, link sentence). After confirmation, save only into a portfolio map copy the user named. Do not change other documents.
```

## 2. Subprojects and roles

```
Study the long-bet draft.

Ask the user to list living subprojects with generic names only (at most five). Wait.

For each row, ask the role this cycle: main, parallel, or background. Wait after each row.

Enforce: exactly one main. If they mark two as main, ask which one owns Monday morning. Wait.

Ask for a stop list on the main row (what we will not do). Wait.

Ask for an attention-quota note on each background row (how little time). Wait.

Remind: background must not take the main Monday slot. Parallel stays visible; the week sheet still carries one bet and one threshold.

Show the table draft. After confirmation, save to the portfolio map. Do not change other documents.
```

## 3. Constraint versus noise

```
Study the portfolio table.

Ask: which single constraint blocks progress on the long bet this week? Wait.

If they name the loudest or hottest workstream, ask: does that line actually block the long bet, or is it noise next to the real constraint? Wait for a clear choice.

Ask where the numbers for that constraint live (SoT path or notebook name). A cycle overview page is not the SoT. Wait.

Do not invent a metric. If unknown, write unknown.

Add constraint, SoT note, and "why not the noisy line" to the portfolio map after confirmation.
```

## 4. One calendar for the portfolio

```
Study the portfolio map.

Confirm out loud: one Monday morning judge-and-plan slot for the whole portfolio; one Friday morning mid-check with no outcome. Wait for yes or adjust.

Ask whether any background row invented its own Friday decision ritual. If yes, ask to drop it. Wait.

Save the calendar confirmation on the map. Then ask whether the main subproject needs its own nested board (template 10) or only the shared week sheet (template 05). Wait.

If nested board: run the checklist questions from template 10 one box at a time.
If shared week sheet only: hand off to basic-cycle section "Week sheet and journal" for the main bet only.
```

## 5. Hand-off to the week

```
Study the filled portfolio map.

State the main bet in one line (from the map). Ask the user to confirm. Wait.

Open basic-cycle prompts for week sheet and Monday or Friday meeting for that main line only. Do not reopen role selection unless the user changes main.
```
